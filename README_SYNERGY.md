# 4T1J — командная синергия

## Что добавлено

- OpenDota собирается не из браузера при каждом открытии страницы.
- Синхронизатор сохраняет найденные матчи в `team_matches`.
- Агрегаты 2/3/4/5 игроков сохраняются в `team_synergy_stats`.
- Публичный сайт читает только готовую аналитику из Supabase.
- GitHub Actions запускает обновление каждые 6 часов и также при push/manual запуске.

## Один раз в Supabase

Запусти обновлённый `supabase-schema.sql` целиком в SQL Editor. Он создаст таблицы `team_matches` и `team_synergy_stats`.

## GitHub Secret

В репозитории открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:

`SUPABASE_SERVICE_ROLE_KEY` — service role key проекта Supabase.

Не вставляй этот ключ в код сайта, `src/` или `.env`, и не отправляй его в чат. Он используется только внутри GitHub Actions.

`VITE_SUPABASE_URL` уже используется существующим workflow и повторно добавлять его не нужно.

## Первый запуск

После первого push GitHub Actions выполнит начальную синхронизацию за последние 730 дней. Если нужно глубже, в workflow можно добавить `INITIAL_SYNC_DAYS=3650`.

После первого успешного запуска открой `https://4t1j.ru/synergy`.

## Что считается

Матч засчитывается комбинации только если выбранные игроки были на одной стороне. Поэтому пара, тройка, четвёрка и пятёрка отражают именно совместную командную игру.

Для 5 игроков доступны 10 пар, 10 троек, 5 четвёрок и 1 полная пятёрка — всего 26 комбинаций.
