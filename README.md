# Dota Draft Training

Чистый сайт для тренировки драфтов Dota 2. В интерфейсе нет информации о команде 4T1J, составах, новостях или медиа.

## Возможности
- создать комнату и пригласить друзей по коду/ссылке;
- капитаны Radiant и Dire;
- режим наблюдателя;
- пики и баны по очереди;
- поиск героев и запрет повторного выбора;
- список героев из OpenDota API с локальным запасным списком;
- адаптивный тёмный интерфейс.

## Запуск локально
1. Установи Node.js LTS: https://nodejs.org/
2. Открой терминал в папке проекта.
3. Выполни:
   ```bash
   npm install
   npm run dev
   ```
4. Открой адрес, который покажет Vite (обычно http://localhost:5173).

## Подключение Supabase для онлайн-комнат
1. Создай проект на https://supabase.com/.
2. Открой SQL Editor и выполни содержимое `supabase-draft-rooms.sql`.
3. В GitHub открой Settings → Secrets and variables → Actions и добавь:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
4. Запусти GitHub Actions workflow для публикации.

Публичный ключ Supabase предназначен для браузерного приложения, но доступ ограничивается RLS. Текущие политики открыты для тестового MVP: любой пользователь с публичным ключом может читать и изменять комнаты. Не используй эту конфигурацию для приватных данных; перед публичным запуском добавь проверку участников и ходов на сервере.

## GitHub Pages
Проект содержит workflow `.github/workflows/deploy.yml`. Проверь `base` в `vite.config.js` под адрес публикации. Для пользовательского домена обычно `/`; для URL вида `username.github.io/repository/` укажи `base: "/repository/"`.

## Что пока не реализовано
- проверенный процент победы на основе полной исторической выборки;
- полноценная точная копия профессионального Captain's Mode;
- серверная валидация очереди ходов и авторизация игроков.

Это независимый фанатский тренажёр. Dota 2 и игровые материалы принадлежат их правообладателям.
