# Dota Replay Analyzer

Локальный веб-сайт для разбора повторов Dota 2 через готовый open-source парсер **gem-dota**.

## Возможности
- Ввод Match ID и попытка автоматически скачать повтор через `gem.fetch_replay()` (источник — OpenDota).
- Ручная загрузка файла `.dem`.
- Извлечение статистики матча и игроков: счёт, длительность, K/D/A, LH, GPM, net worth, урон героям и урон башням (если поле присутствует в версии/повторе).
- Интерфейс в тёмном киберспортивном стиле.
- Скачивание JSON-отчёта, когда парсер предоставляет сериализацию.
- Все файлы и обработка остаются на компьютере, пока приложение запущено локально.

## Требования
- Windows 10/11
- Python 3.10+, рекомендуется Python 3.11 или 3.12
- Интернет для установки библиотек и автоматического скачивания повторов
- Для больших матчей желательно иметь несколько гигабайт свободной оперативной памяти

## Запуск
1. Распакуй ZIP в отдельную папку.
2. Установи Python с https://www.python.org/downloads/ и отметь `Add Python to PATH`.
3. Дважды нажми `install.bat` и дождись установки.
4. Дважды нажми `run.bat`.
5. Открой в браузере `http://127.0.0.1:5000`.
6. Введи Match ID или загрузи `.dem`.

## Как работает автоматическое скачивание
Приложение вызывает `gem.fetch_replay(match_id, replay_dir)`. Повторы доступны не всегда: Valve/OpenDota могут не иметь старого файла, а конкретный матч может быть приватным, неполным или неподдерживаемым. Если скачивание не удалось, попробуй загрузить `.dem` вручную.

## Важные ограничения первой версии
- Это рабочий прототип интерфейса и пайплайна парсинга, а не готовый ИИ-тренер.
- Парсер извлекает данные, но сам по себе не определяет объективно «плохие решения». Для этого понадобится отдельный слой аналитики с правилами и проверкой игровых контекстов.
- Поля могут отсутствовать в некоторых повторах. Старые, повреждённые или обрезанные файлы могут разобрать только частично.
- В зависимости от версии gem-dota и доступности источника может потребоваться небольшая адаптация API вызова скачивания.
- Не публикуй загруженные повторы и отчёты, если не хочешь делиться содержимым матча.

## Структура
- `app.py` — Flask backend, скачивание и парсинг.
- `templates/index.html` — интерфейс.
- `static/style.css` — оформление.
- `static/app.js` — загрузка и отображение результата.
- `replays/` — загруженные повторы.
- `reports/` — JSON-отчёты.

## Если возникла ошибка
- Запусти `install.bat` заново, если зависимости не установились.
- Убедись, что ID содержит только цифры.
- Попробуй загрузить `.dem` вручную.
- Если ошибка связана с конкретным атрибутом/версией парсера, сохрани текст ошибки из окна терминала для диагностики.
