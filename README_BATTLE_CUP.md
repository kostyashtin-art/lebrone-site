# Боевой кубок 4T1J

На главной странице блок «Статистика состава / OpenDota» заменён на расписание еженедельного Боевого кубка.

- Старт: каждую субботу в 21:00 по Москве (МСК).
- На сайте показывается живой обратный отсчёт до ближайшего старта.
- После подключения Supabase на главной отображаются победы/поражения и последние результаты.
- В `/admin` авторизованный администратор может добавить результат кубка: дата, победа/поражение, счёт, соперник и заметка.

## База данных

В `supabase-schema.sql` добавлена таблица `battle_cups`. Если схема ещё не запускалась — запусти весь файл в Supabase SQL Editor.

Если предыдущая схема уже была запущена, выполни только блок, начинающийся с:

```sql
create table if not exists public.battle_cups
```

## Как отмечать победы

После каждого субботнего кубка в админке добавляется одна запись. На главной она превращается в `W` (победа) или `L` (поражение), а общий счёт автоматически пересчитывается.
