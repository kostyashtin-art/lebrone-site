# 4T1J Homepage Redesign

This version implements the cinematic homepage concept while preserving the existing roster profiles, Battle Cup, highlights/Supabase, synergy analytics, auth/admin, and GitHub Pages deployment.

## Homepage sections
- cinematic hero with GOOD PEOPLE. GOOD DOTA.
- live Dota status card in the hero, powered by the existing OpenDota live endpoint
- five-player roster strip
- latest Battle Cup result + Battle Cup-based team performance + milestones
- existing compact Battle Cup widget
- dynamic media showcase from published highlights
- 4T1J journey and next goals
- final team values block

## Removed/kept
- support button remains removed
- sponsor-style block remains removed
- player card functionality is unchanged
- existing pages and admin functionality are preserved
