# Закрытая админ-панель 4T1J

Админка больше не находится в меню и не доступна по `/admin`. Служебный URL: `/4t1j-media-control-7f3m9k`.

## Важная защита
1. В Supabase оставьте только свою учётную запись Auth.
2. Выполните обновлённый `supabase-schema.sql`.
3. В таблицу `public.admin_users` добавьте UUID **своего** пользователя Supabase:

```sql
insert into public.admin_users (user_id) values ('ВАШ-UUID-ИЗ-SUPABASE');
```

После этого обычный авторизованный пользователь Supabase не сможет загружать, менять или удалять видео и результаты кубков.

Старый `/admin` специально ведёт на 404. Ссылки на админку на публичном сайте нет.

> Секретный URL не является заменой авторизации. Реальная защита выполняется Supabase Auth + проверкой `admin_users` + RLS.
